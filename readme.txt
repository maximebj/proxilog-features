Extension WordPress personnalisée développée par une agence pour ajouter des options d'administration à WordPress.

== Description ==

Proxilog Features est une extension WordPress personnalisée conçue par une agence pour ses clients. Elle permet d'ajouter facilement des options d'administration personnalisées dans le tableau de bord WordPress.

= Fonctionnalités principales =

* Ajoute une page d'options dédiée dans l'administration WordPress
* Interface simple et intuitive accessible depuis le menu principal
* Icône personnalisée dans le menu d'administration (roue dentée)
* Développé selon les standards WordPress pour garantir la compatibilité
* Code sécurisé avec protection ABSPATH

= Usage =

Une fois l'extension activée, une nouvelle option "Options" apparaîtra dans le menu d'administration de WordPress. Cette page permet de gérer les paramètres personnalisés de votre site.

= Support =

Cette extension est développée et maintenue par une agence pour ses clients. Pour toute question ou assistance, veuillez contacter votre agence.

== Installation ==

= Installation automatique =

1. Connectez-vous à votre tableau de bord WordPress
2. Accédez à Extensions > Ajouter une nouvelle extension
3. Recherchez "Proxilog Features"
4. Cliquez sur "Installer maintenant" puis "Activer"

= Installation manuelle =

1. Téléchargez le fichier ZIP de l'extension
2. Connectez-vous à votre tableau de bord WordPress
3. Accédez à Extensions > Ajouter une nouvelle extension
4. Cliquez sur "Téléverser une extension"
5. Sélectionnez le fichier ZIP et cliquez sur "Installer maintenant"
6. Activez l'extension via le menu "Extensions" de WordPress

= Installation FTP =

1. Téléchargez et décompressez l'extension
2. Uploadez le dossier `proxilog-features` dans le répertoire `/wp-content/plugins/`
3. Activez l'extension via le menu "Extensions" de WordPress
